# 24 · PowerShell: XML invoices into stock / PowerShell: notas XML viram estoque

![demo](prints/demo_1366.png)

## EN

**Business problem.** Inbound and outbound invoices arrive as XML. Someone opens them one by one and types quantities into a stock sheet. A typo, a forgotten invoice or the same invoice posted twice leaves the balance different from the shelf.

**What it does.** `stock.ps1` (Windows PowerShell 5.1, built into Windows) processes every `*.xml` in the inbox, in name order. Each invoice is **all or nothing**:
- applied → `stock.csv` updated, `ledger.csv` appended (audit trail), file to `processed\`
- invoice number already in the ledger → ignored, file to `duplicates\`, exit 0
- broken XML, missing number/date/direction/items, unknown SKU, qty not a positive integer, or a balance that would go negative → file to `rejected\` with a `.reason.txt`, stock untouched, exit 2

**Honest gain estimate.** ~3 min per 5-item invoice by hand; 30 invoices a week ≈ 1.5 h. Estimate, not measurement. The bigger gain is not having a wrong balance. The XML layout is simplified; real invoices have more fields and need their layout mapped.

**Stack.** Windows PowerShell 5.1, XML, CSV, Task Scheduler (`schtasks`). Python only runs the tests. This replaces the Power Automate Desktop item of the plan (not installed, flows cannot be generated by script).

**Run.**
```
python make_data.py
powershell -NoProfile -ExecutionPolicy Bypass -File stock.ps1 -Inbox inbox -Data data -Results out.json
python run_scenarios.py     # 7 invoices one at a time + one batch -> output/scenarios.json
python tests/test_stock.py  # 9 checks, the batch ends on the same stock
```
**Demo:** `../../demos/24-powershell-notas-estoque/`.

## PT

**Problema de negócio.** Notas de entrada e saída chegam em XML. Alguém abre uma a uma e digita as quantidades numa planilha. Erro de digitação, nota esquecida ou lançada duas vezes deixa o saldo diferente da prateleira.

**O que faz.** `stock.ps1` (Windows PowerShell 5.1, já vem no Windows) processa cada `*.xml` da pasta. Cada nota é **tudo ou nada**: aplicada (atualiza `stock.csv`, acrescenta `ledger.csv`, vai para `processed\`); repetida (ignorada, `duplicates\`, saída 0); XML quebrado, campo faltando, SKU desconhecido, quantidade inválida ou saldo negativo (vai para `rejected\` com `.reason.txt`, estoque intacto, saída 2).

**Ganho estimado (honesto).** ~3 min por nota de 5 itens; 30 notas por semana ≈ 1,5 h. Estimativa, não medição. O formato do XML é simplificado; notas reais exigem mapear o layout.

**Stack.** PowerShell 5.1, XML, CSV, Agendador de Tarefas. Substitui o item Power Automate Desktop do plano (não instalado; fluxos não são gerados por script).

**Como rodar.** Comandos acima. Saídas reais em `output/`. Demo em `../../demos/24-powershell-notas-estoque/`.
