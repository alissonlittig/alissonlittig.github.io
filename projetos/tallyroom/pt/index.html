    10:15Sai um cabo USB-C. Restam três.Entra na lista de reposição. A tela diz 3, não mais ou menos 3.

    O que faz

    Feito para o balcão, não para o escritório

    Quatro tarefas, uma tela. Nada para instalar no caixa.

    01

    Leia e venda

    Qualquer leitor USB funciona, ou a câmera do celular. Divida a venda entre dinheiro e cartão, ou em parcelas, com um toque.

    Como a venda funciona
    02

    Uma contagem que anda sozinha

    Cada venda tira um. Uma entrega devolve. O número na tela é o número na prateleira.

    Como a contagem se mantém certa
    03

    Lista de reposição antes do fim de semana

    Defina um mínimo por produto. Quando a contagem chega nele, o item entra numa lista com a quantidade a comprar.

    04

    Feche o dia em um minuto

    Dinheiro, cartão e retiradas se somam sozinhos. Se o caixa não bate, você vê a diferença antes de trancar a loja.

    Para começar

    Funcionando em uma tarde

    1

    Traga seus produtos

    Cole uma planilha ou digite. Os códigos de barras são lidos uma vez.

    2

    Conte a prateleira

    Uma volta com o celular define os números iniciais.

    3

    Venda como sempre

    Leia, receba, entregue o recibo.

    4

    Reponha pela lista

    Ligue para o fornecedor com quantidades, não com palpites.
