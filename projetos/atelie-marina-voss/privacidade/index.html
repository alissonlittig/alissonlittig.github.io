Privacidade

Como usamos seus dados

Este é um site de demonstração de uma marca fictícia. Ele não tem servidor próprio, não usa cookies de rastreamento e não envia o que você digita para lugar nenhum.

Formulário de encomenda. Os campos servem apenas para montar o texto de uma mensagem no seu navegador. Você decide se abre o WhatsApp e envia. Se enviar, o WhatsApp passa a tratar os dados conforme a política dele.

Armazenamento local. Guardamos no seu navegador apenas a escolha “Reduzir movimento”, para lembrar dela na próxima visita.

Dados de exemplo. O número de WhatsApp, os preços e as obras são exemplos. Em uma versão real, o controlador dos dados seria a artista.
